# Agent rules — frozen v1

1. Read and obey LESSONS.md first. New mistakes are recorded in your worktree only with exact four-line evidence format from AGENT.md. Never edit old lesson entries. Integrator deduplicates lessons on merge.
2. Each Claude Code worker uses its own sibling Git worktree and task branch. Never start subagents. Never edit another worktree, another worker directory, core, go.mod/go.sum, global docs or shared root config. No global config edits. Ask orchestrator for interface/dependency changes in result.txt and report concise request.
3. Only SPEC.md directory allowlist may be edited. result.txt and appended LESSONS.md are reporting exceptions; do not commit SPEC.md/result.txt. No permanent fake runtime implementations, skipped tests, hardcoded secrets, external credential requirements, arbitrary shell execution from mail or email-driven prompts.
4. Use context, slog, injected network clients, bounded timeouts, errors.Is. Run gofmt, package tests, vet. Commit only owned paths and your lesson additions to task branch. Never merge or push. Report actual commit SHA, files, commands/output, unresolved issues, requested deps, security concerns and acceptance matrix.
5. Frozen public APIs are in docs/contracts.md and core. Read docs/architecture.md and docs/database-schema.md. Transactions must protect cursor+email+invoice+outbox and transitions; no network inside DB transaction. Tests use embedded core.Repository fakes for independent compilation.
6. Runtime dependency versions already pinned by orchestrator. Don't run go get/mod tidy. CLI stays interactive via Herdr per local user instructions, using acceptEdits and narrowly allowed go/git commands, configured user default model. Do not change permission settings or bypass prompts. Worktree placement and branch conventions follow explicit user requirements; orchestrator creates sibling worktrees outside Claude sandbox.
7. Time limit per initial implementation lane 30 minutes; report blockers early. Finish clear functional scope with real tests; never claim unsupported features. T08 composition waits for modules before final wiring; deployment/config can be implemented independently.
